# GTEMS OS 1.0 Aurora — Documentación Oficial

> **GTEMS OS es un sistema operativo basado en Linux, diseñado para ofrecer un entorno de escritorio moderno, personalizable y funcional. Integra herramientas de productividad, navegación, programación, administración de archivos y dispositivos, conectividad y configuración del sistema en una plataforma preparada para evolucionar.**

**Slogan oficial:** «Diseñado por cinco mentes, construido para el futuro.»

## Índice de Manuales
- `MANUAL_INSTALACION.md`: Requisitos, grabación USB, arranque BIOS/UEFI, instalación en disco y pruebas en máquina virtual.
- `MANUAL_USUARIO.md`: Uso diario del escritorio GTEMS OS, barra lateral izquierda, buscador global, personalización ZEYLA/Aurora, GTEMS Code Studio, Terminal y descargas.
- `MANUAL_COMPILACION.md`: Generación de la imagen `.iso` híbrida arrancable mediante `Makefile`, `Dockerfile` y scripts `GTEMS-OS/build/*.sh`.
- `ARQUITECTURA_TECNICA.md`: Base Debian Linux, capas del sistema, modo Live vs persistencia, seguridad y límites reales del entorno web/sandbox.
