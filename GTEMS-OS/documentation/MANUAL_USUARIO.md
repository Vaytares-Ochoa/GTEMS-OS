# Manual de Usuario — GTEMS OS 1.0 Aurora

## 1. Escritorio y Barra Lateral de Tareas
- La barra lateral izquierda permanente agrupa el botón **Inicio**, el **Buscador global (`Ctrl+K`)**, tus aplicaciones fijadas/abiertas y la bandeja vertical (Red, Bluetooth, Volumen/Notificaciones, Dispositivos, Batería y Reloj/Calendario).
- Puedes ajustar su densidad (compacta, normal o expandida) o moverla desde **Configuración → Personalización**.

## 2. Buscador Global (`Ctrl+K`)
Busca en tiempo real aplicaciones, carpetas, archivos y contenido interno, ajustes, procesos activos, dispositivos reales o lanza búsquedas en Internet directamente en el navegador.

## 3. Personalización (ZEYLA & Aurora)
En **Configuración → Personalización** puedes elegir entre los temas visuales (`ZEYLA Aurora`, `ZEYLA Neon`, `ZEYLA Pastel`, `ZEYLA Dream`, `ZEYLA Midnight`, `ZEYLA Crystal` o `Personalizado`), subir fondos locales para Escritorio y Pantalla de Bloqueo, ajustar transparencia, animaciones y cursores reales SVG.

## 4. Aplicaciones Principales
- **GTEMS Explorer**: Navegación de `/Inicio`, `/Documentos`, `/Descargas`, `/Imágenes`, `/Música`, `/Vídeos`, `/Proyectos`, `/Papelera` y `/Sistema` (solo lectura). Soporta selección múltiple (`Ctrl`/`Shift`/`Ctrl+A`), compresión/extracción `.zip`, menú contextual y `Abrir en terminal`.
- **GTEMS Code Studio**: IDE multipestaña sobre `/Proyectos` con ejecución real y detención controlada para Python, JavaScript/TypeScript, C/C++, SQLite y Bash.
- **Terminal**: Consola Bash real con `gtemsctl`, autocompletado e historial persistente de 20 comandos (con ocultamiento automático de credenciales).
- **Navegador Web y Descargas**: Inspección HTTPS real, detección de navegadores Linux instalados y gestor de descargas con pausa/reanudación (`Range`) y verificación SHA-256.
- **Multimedia e Imágenes**: Editor de imágenes con recorte, rotación, filtros, deshacer y confirmación antes de sobrescribir originales; reproductores reales de audio y vídeo.

## 5. Descarga de la Imagen `.iso` y Recuperación
En **Configuración → Sistema → Descargar GTEMS OS** puedes comprobar si el servidor dispone de una imagen `.iso` compilada, inspeccionar su huella `SHA-256` y descargarla directamente.
